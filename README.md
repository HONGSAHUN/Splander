# Splander

컴퓨터 1~3명과 즐기는 비공식 스플렌더 기본판 웹 게임입니다. 각 컴퓨터에 하·중·상·최상·마스터 난이도를 따로 지정할 수 있습니다.

## 실행

`dist/index.html`을 브라우저에서 열거나, Python 3가 설치된 환경에서 아래 명령을 실행합니다.

```sh
python3 -m http.server 4173 --directory dist
```

그다음 http://localhost:4173 으로 접속합니다. 게임 서버나 API 키, 패키지 설치가 필요 없습니다. 폰트만 외부 Google Fonts를 사용하며, 연결이 없으면 기본 폰트로 표시합니다.

## 난이도

| 난이도 | 판단 방식 |
| --- | --- |
| 하 | 무작위 보석 수집과 구매 |
| 중 | 현재 구매 가능 카드 및 목표 비용 평가 |
| 상 | 목표 카드 효율·보석 조합·황금 예약 평가 |
| 최상 | 자신의 2회 행동을 탐색해 할인 누적, 귀족, 점수 효율을 비교 |
| 마스터 | 자신의 3회 행동 탐색과 상대들의 공개 카드 구매·예약 예측, 즉시 승리 차단 |

높은 난이도도 추가 자원을 받지 않습니다. AI는 공개된 시장, 공개 자원과 보너스, 자신의 예약 카드만 이용합니다. 카드 더미 순서와 상대의 비공개 예약 카드 내용은 읽지 않습니다. 미래의 카드 보충을 예측하지 않는 제한된 탐색이므로 완전한 최적 플레이를 보장하지는 않습니다.

## 적용 규칙

- 개발 카드 90장: 1단계 40 / 2단계 30 / 3단계 20.
- 보너스로 비용을 할인한 뒤 토큰을 지불합니다. 황금은 부족한 색을 대체합니다.
- 서로 다른 색 최대 3개 또는 은행에 해당 색이 4개 이상 있을 때 같은 색 2개를 가져옵니다.
- 예약 최대 3장. 예약 시 은행에 황금이 있으면 1개 받습니다.
- **황금 포함 턴 종료 시 최대 10개**. 초과 시 반환 창에서 선택해야 다음 턴으로 넘어갑니다. 이전 구현의 '10개 초과 획득 차단 및 AI 턴 건너뛰기'를 수정했습니다.
- 한 턴에 귀족 1명, 귀족당 3점. 15점 도달 시 같은 라운드를 마치고 순위를 정합니다.
- 동점이면 구매 카드가 적은 플레이어가 승리하고, 카드 수도 같으면 공동 승리합니다.

## 검증

Node.js 18 이상에서 다음을 실행합니다. 외부 의존성 설치는 필요 없습니다.

```sh
npm test
node tests/benchmark.cjs
```

카드 전수 대조, 할인·황금 지불, 예약 제한, 초과 반환 시 턴 잠금, 고난도 AI의 승리/방어 선택, 비공개 정보 미사용을 검사합니다. 벤치마크는 같은 시드에서 선후공을 바꿔 최상·마스터와 상을 대결시키며 모든 턴에서 칩 보존과 카드 중복 여부를 검사합니다.
